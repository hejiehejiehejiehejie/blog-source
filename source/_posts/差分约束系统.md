**差分约束系统** 是一种特殊的 $n$ 元一次不等式组，它包含 $n$ 个变量，以及 $m$ 个约束条件，每个条件是有两个变量做差构成的，形如 $x_i - x_j \leq c_k$. 我们要解决的问题是：求一组解，使得所有的约束条件得到满足，否则判断出无解.

## 1. 变形

差分约束系统中的每个约束条件：
$$
x_i - x_j \leq c_k
$$
都可以变形成：
$$
x_i \leq x_j + c_k
$$

## 2. 转化

接下来，思考一个图论的问题。

*   `dist[i]` 是从起点到 $i$ 地的最短距离
*   `dist[j]` 是从起点到 $j$ 地的最短距离
*   $c$ 是从 $j$ 地到 $i$ 地的路线长度（边权）

则 $dist[i] \leq dist[j] + c$ 是必然的，否则 `dist[i]` 就不是最短的距离。

所以，在最短路算法中，其本质工作就是检查所有的边，确保图中所有的边都满足 $dist[i] \leq dist[j] + c$ 这个条件。

到这里，我们发现这两个式子格式完全一样，但是虽然两者代数关系相同，但是想直接关联起来还是比较抽象。

我们不妨画一张这样的图，虚构一个不存在的“起点”，连一条虚边指向 $i$ $(1 \leq i \leq n)$，边权为最短路 `dist[i]` 的值。

![](https://img.998244353.best/img/graph1787842422090.svg)

于是，根据单源最短路的定义，我们轻易知道，最短路不成立的情况就是有负环的情况。

所以对于不等式：
$$
x_i \leq x_j + c_k
$$
可以连接从 $j$ 到 $i$ 的一条边，连接所有不等式构成的边，构建出最后的图。

## 3. 实现

可以用 `SPFA` 来判断图中是否出现负环，具体的做法是：开一个 `cnt` 数组记录最短路径上边的个数，当成功松弛操作之后，即若 $dist[u] > dist[v] + c$，让 $cnt[u] = cnt[v] + 1$。当最短路边的个数大于等于所有点的个数时，说明出现了负环。

### 例题1：[【模板】差分约束](https://www.luogu.com.cn/problem/P5960)

```cpp
#include <bits/stdc++.h>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<vector<array<int, 2>>> adj(n + 1);
    
    int u, v, w;
    while (m --) {
        cin >> u >> v >> w;
        adj[v].push_back({u, w});
    }

    queue<int> q;
    vector<int> d(n + 1), cnt(n + 1);
    for (int i = 1; i <= n; i ++) q.push(i);

    while (q.size()) {
        auto u = q.front();
        q.pop();
        for (auto [v, w] : adj[u]) {
            if (d[v] > d[u] + w) {
                cnt[v] = cnt[u] + 1;
                if (cnt[v] >= n) {
                    cout << "NO\n";
                    return 0;
                }
                q.push(v);
                d[v] = d[u] + w;
            }
        }
    }

    for (int i = 1; i <= n; i ++) cout << d[i] << " \n"[i == n];

    return 0;
}
```

### 例题2: [CF2245D2](https://codeforces.com/contest/2245/problem/D2)

这个问题的核心是将其转换为带有差分约束（Difference Constraints）和 2-SAT 思想的图论模型。由于数组中的元素不仅有正负关系，还要满足大于等于 0 或小于 0 的条件，我们可以通过引入互为相反数的变量，将原问题转化为单源最长路问题。

### 核心推导与模型构建

对于数组中的每一个变量 $a_i$，我们在图中构建两个节点：

* 节点 $i$ 代表正变量 $+a_i$。
* 节点 $i'$ 代表负变量 $-a_i$。

将题目给出的约束条件转换为节点间距离的不等式 $p(v) \ge p(u) + w$，即从节点 $u$ 向节点 $v$ 连一条权值为 $w$ 的有向边：

1. **对于 $o=1$ ($a_i + a_j \ge 0$)：**
可以变形为 $a_i \ge -a_j$ 和 $a_j \ge -a_i$。
这等价于我们需要从节点 $j'$ 向 $i$ 连一条权值为 0 的有向边，并从节点 $i'$ 向 $j$ 连一条权值为 0 的有向边。
2. **对于 $o=2$ ($a_i + a_j < 0$)：**
因为数组全为整数，等价于 $a_i + a_j \le -1$，进而变形为 $-a_i \ge a_j + 1$ 和 $-a_j \ge a_i + 1$。
这等价于我们需要从节点 $j$ 向 $i'$ 连一条权值为 1 的有向边，并从节点 $i$ 向 $j'$ 连一条权值为 1 的有向边。

### 合法性判定与赋值策略

由于图中所有边权均为非负数（$0$ 或 $1$），如果图中存在任何权值之和大于 0 的环（即正权环），则意味着出现了 $p(v) \ge p(v) + W\ (W > 0)$ 的自相矛盾，此时无解（对应输出 `NO`）。

为了判定正权环并得出每个变量的最长路：

1. **找强连通分量 (SCC)：** 运行 Tarjan 算法。因为环只能在同一个 SCC 内部，如果某个 SCC 内包含哪怕一条权值为 1 的边，就必定存在正权环，直接返回 `NO`。
2. **在 DAG 上求最长路：** 如果所有的权值为 1 的边都跨越不同的 SCC，说明图是合法的。我们将 SCC 缩点成有向无环图 (DAG)。由于 Tarjan 算法求出的 SCC 编号天然呈**逆拓扑序**，我们可以直接按 SCC 编号从大到小对全图执行动态规划计算最长路，设为 $dp[u]$。
3. **计算最终答案：** 赋值 $a_i = dp[i] - dp[i']$ 即可完美满足所有不等式条件，输出对应的数组。

### C++ 完整实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

struct Edge {
    int to;
    int w;
};

void solve() {
    int n, m;
    if (!(cin >> n >> m)) return;

    // 节点 1~n 代表正数 +a_i，节点 n+1~2n 代表相反数 -a_i
    vector<vector<Edge>> adj(2 * n + 1);
    auto neg = [&](int x) { return x + n; };
    auto pos = [&](int x) { return x; };

    for (int k = 0; k < m; ++k) {
        int type, i, j;
        cin >> type >> i >> j;
        if (type == 1) {
            adj[neg(j)].push_back({pos(i), 0});
            adj[neg(i)].push_back({pos(j), 0});
        } else {
            adj[pos(j)].push_back({neg(i), 1});
            adj[pos(i)].push_back({neg(j), 1});
        }
    }

    int timer = 0, scc_cnt = 0;
    vector<int> dfn(2 * n + 1, 0), low(2 * n + 1, 0), scc(2 * n + 1, 0);
    vector<int> st;
    vector<bool> in_st(2 * n + 1, false);

    // Tarjan 求强连通分量 (SCC)
    auto dfs = [&](auto& self, int u) -> void {
        dfn[u] = low[u] = ++timer;
        st.push_back(u);
        in_st[u] = true;

        for (auto& edge : adj[u]) {
            int v = edge.to;
            if (!dfn[v]) {
                self(self, v);
                low[u] = min(low[u], low[v]);
            } else if (in_st[v]) {
                low[u] = min(low[u], dfn[v]);
            }
        }

        if (low[u] == dfn[u]) {
            scc_cnt++;
            while (true) {
                int v = st.back();
                st.pop_back();
                in_st[v] = false;
                scc[v] = scc_cnt;
                if (u == v) break;
            }
        }
    };

    for (int i = 1; i <= 2 * n; ++i) {
        if (!dfn[i]) dfs(dfs, i);
    }

    // 校验是否存在正权环 (同一个 SCC 内部存在权值为 1 的边)
    bool possible = true;
    for (int u = 1; u <= 2 * n; ++u) {
        for (auto& edge : adj[u]) {
            if (edge.w == 1 && scc[u] == scc[edge.to]) {
                possible = false;
                break;
            }
        }
        if (!possible) break;
    }

    if (!possible) {
        cout << "NO\n";
        return;
    }

    vector<vector<int>> scc_nodes(scc_cnt + 1);
    for (int i = 1; i <= 2 * n; ++i) {
        scc_nodes[scc[i]].push_back(i);
    }

    // Tarjan 得到的 scc 编号是逆拓扑序，所以从 scc_cnt 到 1 进行遍历即为正常的拓扑序
    vector<int> dp(scc_cnt + 1, 0);
    for (int i = scc_cnt; i >= 1; --i) {
        for (int u : scc_nodes[i]) {
            for (auto& edge : adj[u]) {
                int v = edge.to;
                dp[scc[v]] = max(dp[scc[v]], dp[i] + edge.w);
            }
        }
    }

    cout << "YES\n";
    for (int i = 1; i <= n; ++i) {
        long long val = (long long)dp[scc[pos(i)]] - dp[scc[neg(i)]];
        cout << val << (i == n ? "" : " ");
    }
    cout << "\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```
