### 1. 强哥德巴赫猜想（关于偶数）这是我们通常所说的“哥德巴赫猜想”，其内容是：任一大于 2 的偶数，都可以表示成两个质数之和。

例子：

$4 = 2 + 2$

$6 = 3 + 3$

$8 = 3 + 5$

$10 = 3 + 7 = 5 + 5$

$100 = 3 + 97 = 11 + 89 = ...$

虽然数学家们利用计算机已经验证到了 $4 \times 10^{18}$ 这么大的数，且所有结果都符合猜想，但至今还没有人能从数学上严格证明它对所有偶数都成立。

### 2. 弱哥德巴赫猜想（关于奇数）又称“三素数猜想”，其内容是：任一大于 5 的奇数，都可以表示成三个质数之和。

例子：

$7 = 2 + 2 + 3$

$9 = 3 + 3 + 3$

$11 = 3 + 3 + 5$

现状： 弱哥德巴赫猜想在 2013 年已经由数学家哈洛德·贺欧夫各特（Harald Helfgott）宣布完成了最终证明。这意味着对于奇数的情况，我们在数学上已经确定它是正确的了。
